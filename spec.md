# Specification

## Summary
**Goal:** Fix two broken profile editing features: the Save Profile button error and the non-functional banner upload button.

**Planned changes:**
- Fix the backend profile update call so that saving name, handle, bio, location, and profile photo succeeds without a "failed to update profile" error
- Fix the banner upload button on the profile page so tapping it opens a file picker, uploads the selected image, and persists it as the profile banner

**User-visible outcome:** Users can successfully save profile changes and upload a banner image without encountering errors.
