# Specification

## Summary
**Goal:** Add TikTok-style vertical snap-scrolling and an auto-scroll toggle to the ShortSportPage.

**Planned changes:**
- Update ShortSportPage so each reel occupies the full viewport height with snap-scroll behavior, allowing users to swipe/scroll up and down to navigate between reels one at a time.
- Add a floating auto-scroll toggle button in the bottom-right corner that, when active, automatically advances to the next reel at a set interval and visually indicates its active/inactive state.

**User-visible outcome:** Users can manually swipe through sport reels vertically with smooth snap-scrolling, and can toggle auto-scroll mode to have reels advance automatically.
